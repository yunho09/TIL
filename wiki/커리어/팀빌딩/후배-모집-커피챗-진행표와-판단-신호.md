# 후배 모집 커피챗 진행표와 판단 신호

ToyVillage 프로젝트에 들어올 프론트엔드 후배를 보는 **30분 커피챗**의 진행표, 섹션별 판단 신호, 우리가 말할 내용을 정리했다. 실력보다 **같이 오래 일할 수 있는지**(태도·꾸준함·소통)를 보며, "막혔을 때" 섹션에 시간을 가장 많이 쓴다. 질문과 신호는 Claude가 제안하고 사용자가 고쳐 간 안이며, 실제 진행 결과는 반영돼 있지 않다.

## 진행표 (30분)

| 순서 | 섹션 | 시간 | 질문 |
|---|---|---|---|
| 0 | 시작 | 2분 | 인사, 면접이 아니라 서로 맞는지 보는 자리라고 알리기 |
| 1 | 요즘 하는 것 | 5분 | 지금 하는 프로젝트·공부 / 하나 보여 주며 한 줄 소개 / 재밌는 점과 어려운 점 |
| 2 | 왜 토이빌리지인가 | 3분 | 알게 된 경로와 끌린 점 / 얻어 가고 싶은 것 |
| 3 | 시간과 꾸준함 | 3분 | 주당 가능 시간 / 끝까지 해 본 프로젝트, 그만둔 이유 |
| 4 | **막혔을 때** | 7분 | 오래 막힌 문제와 해결 과정 / 언제 물어보는지 / 코드 리뷰 지적 |
| 5 | 협업 | 4분 | 팀에서의 역할 / 의견이 달랐을 때 |
| 6 | 기술 | 3분 | 1번에서 보여 준 것의 아쉬운 부분 |
| 7 | 마무리 | 3분 | 우리가 말할 것 + 궁금한 것 받기 |

- 개발을 언제·왜 시작했는지는 **묻지 않기로** 했다(사용자 결정). 대신 "요즘 하는 것"으로 연다.
- 초반에 결과물을 하나 보여 달라고 하면 기술 섹션에서 그대로 이어 물을 수 있다.
- Git 사용 수준(브랜치·PR·충돌)은 코드를 보여 줄 때 확인할 수 있어 별도 질문에서 뺐다.

## 섹션별 볼 것과 신호

| 섹션 | 볼 것 | 좋은 신호 | 걸리는 신호 | 꼬리 질문 |
|---|---|---|---|---|
| 요즘 하는 것 | 직접 만든 건지 따라 만든 건지 | 쉽게 설명하고 어려운 점이 구체적 | 기술 이름 나열로 끝남 | 직접 짠 거야? 왜 만들었어? |
| 지원 동기 | 이 프로젝트에 대한 관심인지 | 얻고 싶은 게 구체적 | "그냥요", "포폴용이요"뿐 | 해 보고 싶은 기능·화면이 있어? |
| 시간·꾸준함 | 계획이 현실적인지 | 바쁜 시기를 먼저 말함 | 흐릿한 답, 동시에 하는 게 너무 많음 | 시험·대회 기간엔 어떻게 할 거야? |
| 막혔을 때 | 문제를 쪼갠 과정 | 원인까지 말하고 적당한 때 물어봄 | "그냥 해결됐어요", 며칠씩 혼자 붙잡음, 리뷰를 불편해함 | 뭘 찾아봤어? AI를 어떻게 썼어? 원인이 뭐였어? |
| 협업 | 자기 역할 인식 | 대화로 풀고 자기 실수도 말함 | 팀원 탓으로만 설명 | 다시 하면 뭘 다르게 할래? |
| 기술 | 자기 코드를 돌아보는지(정답 불필요) | 아쉬운 점과 고칠 방법 | "아쉬운 거 없어요" | 어떻게 고치고 싶어? |

- 그만둔 이유는 탓하는 느낌 없이 가볍게 묻는다.
- 팀 경험이 없으면 "친구랑 같이 뭐 해 본 것"으로 바꿔 묻는다.
- 보여 줄 게 없으면 말로만 들어도 된다.
- 끝나자마자 막혔을 때·꾸준함·협업·관심도를 상·중·하로 적고, 기억에 남는 답 한 줄을 남긴다.

## 우리가 말할 것

- **서비스 소개**: 동물을 돌보는 시설에서 직원들이 업무, 먹이 급여 기록, 관찰 일지, 휴무 일정을 한곳에서 관리하는 서비스. (관리자 화면 코드만 보고 쓴 문장이라 정확한 시설 이름은 확인 필요)
- **처음 맡을 일**: 작은 UI 수정이나 이슈 한두 개로 코드에 익숙해지기
- **스택**: React, TypeScript, Vite, TanStack Query, Zustand, Emotion, Playwright
- **일하는 방식**: 할 일은 Linear, 코드는 PR 리뷰 후 병합
- **힘든 점도 솔직하게**: 바쁜 시기, 꼼꼼한 리뷰
- **얻어 갈 것**: 실사용 서비스 경험, 코드 리뷰를 통한 성장, 포트폴리오
- **커피챗 전에 채울 칸**: 팀 인원, 회의 주기, 기대 주당 시간, 바쁜 시기, 결과 알림 날짜와 방법
- **주의**: 붙는다고 확답하지 않는다. 결과 날짜는 지킬 수 있게 넉넉히 잡는다.

## 분위기 풀기용 질문 방향

- 일상·학교생활보다 상대 분야에 맞춘 질문이 이어 가기 좋다. 프론트 지원자에게는: (Claude 보충)
  - 좋아하는 웹사이트·UI, 만들기 힘들었던 화면·컴포넌트
  - 반응형, API 연동, 로딩·에러 화면, 배포, 상태 관리, 개발자 도구 경험
  - 해 보고 싶은 분야(애니메이션, 3D, 성능, 디자인 시스템)
