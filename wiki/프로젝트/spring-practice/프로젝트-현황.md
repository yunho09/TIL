# spring-practice 프로젝트 현황

스프링 부트 학습용 게시글 CRUD 앱. 사용자(장윤호)는 프론트엔드(JS) 배경으로 자바/스프링을 처음 배우는 중.

## 기술 스택
- Spring Boot 4.1.1, Java 21, Gradle
- MySQL 8 (Docker 컨테이너 `spring-practice-mysql`)
- JPA (spring-boot-starter-data-jpa) + spring-boot-starter-webmvc
- Lombok은 build.gradle에 있으나 **아직 코드에서 안 씀** (학습 목적으로 생성자 직접 작성 중. @RequiredArgsConstructor 개념은 이해한 상태)

## 구조 (4계층)
```
src/main/java/com/example/springpractice/
├── SpringPracticeApplication.java   시작점 (스캔 기준)
├── controller/
│   ├── PostController.java   CRUD 6개 엔드포인트 (와일드카드 import 사용 중)
│   ├── PostRequest.java      record (title, content)
│   └── HelloController.java  GET /hello (생존 확인용)
├── service/PostService.java  create/findAll/findOne/update/delete/search
├── domain/Post.java          @Entity (id: IDENTITY, protected 빈 생성자, setter 없이 update() 메서드)
└── repository/PostRepository.java  interface extends JpaRepository<Post, Long> + findByTitleContaining
```

## API
- POST /posts, GET /posts, GET /posts/{id}, PUT /posts/{id}, DELETE /posts/{id}
- GET /posts/search?keyword=... (쿼리 메서드 findByTitleContaining)

## DB / 환경
- application.yaml: jdbc:mysql://localhost:3306/spring_practice, 계정 spring/spring1234, ddl-auto: update, show-sql: true
- MySQL 컨테이너 재시작: `docker start spring-practice-mysql` (Docker Desktop 먼저: `systemctl --user start docker-desktop`)
- DB 직접 조회: `docker exec spring-practice-mysql mysql -uspring -pspring1234 --default-character-set=utf8mb4 spring_practice -e "SELECT * FROM post;"`

## 주의사항
- **git 저장소 아님** — 커밋 이력 없음, 백업 없음 (git init 권장했으나 아직 안 함)
- 검증 없음: title null이어도 저장됨 (Postman에서 실제로 겪은 버그)
- 없는 id 조회 시 200 + 빈 본문 (404 처리 안 됨)
- 테스트 코드 없음
