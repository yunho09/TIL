# xquare PVE 컨테이너 관리 페이지 퍼블리싱: 결정과 PR 운영

`/container`(CT 관리 Summary, 이슈 #189)와 `/container/create`(CT·VM 생성, 이슈 #190)를 Figma 시안대로 퍼블리싱하며 정한 것과 PR 운영 요령. API 연동 전이라 목업 데이터로 동작하고, 생성 버튼도 실제로 만들지 않고 `/container`로 돌아간다.

## 구조와 PR 운영
- #189 → PR #191(`feature/#189` → `develop`), #190 → PR #192(**base가 `feature/#189`인 스택 PR**). 리뷰어에게 생성 페이지 변경만 보이게 하려는 선택. 머지 순서·base 자동 전환 규칙은 [[Git-스택-PR-재정렬-force-with-lease]].
- **#192는 base가 `develop`이 아니라 빌드·린트 CI가 안 돈다**(develop 대상 PR에서만 트리거되는 것으로 추정). base가 `develop`으로 바뀐 뒤 CI 통과를 확인하고 머지. `Closes #190`도 기본 브랜치로 머지돼야 닫힘([[GitHub-closing-keyword-기본브랜치-PR-자동닫힘과-코드오너-룰셋]]).
- **(2026-11-25 확인) base만 바꿔서는 CI가 돌지 않는다**: 이 저장소 워크플로는 PR이 열릴 때·새 푸시·재오픈에만 트리거된다. #191 머지 후 #192 base를 `develop`으로 바꾸고 **PR을 닫았다 바로 다시 열어** 빌드·린트를 돌렸다(위 "추정"의 실제 해결법).
- **머지 결과**: #191 → `f2e63f1`(#189 닫힘), #192 → `7919439`(#190 닫힘). `develop` 머지마다 스테이징 자동 배포 워크플로가 돌아 둘 다 성공. 저장소가 머지 시 브랜치를 자동 삭제하지 않아 `feature/#189`·`feature/#190`은 develop에 전부 들어간 것을 확인하고 로컬·원격에서 직접 지웠다.
- **커밋 분할**: 한 커밋을 의존 순서(타입·목업 → 목록 → 탭 → 페이지·라우트)로 4개로 쪼갠 뒤, **각 커밋을 체크아웃해 `tsc -b`로 단독 빌드되는지 확인**하고, 분할 전후 diff가 비어 있는지 대조한 다음 `--force-with-lease`로 푸시. 분할 전 커밋은 로컬 태그로 백업했다(백업 브랜치 지양 규칙은 [[Claude-Code-임의-백업-브랜치-생성-지양]]).
- **`.omc/` 상태 폴더가 커밋에 섞여 푸시된 사고**: 여러 하위 폴더에 `.omc/`가 생기는데 `.gitignore`에 없어 `git add <폴더>`/`git add .`에 딸려 올라갔다. 커밋에서 빼고 force-push로 정정한 뒤, **커밋되지 않는 `.git/info/exclude`에 `.omc/`를 추가**해 재발을 막았다(팀 공용 `.gitignore`를 건드리지 않는 로컬 제외). 스테이징할 땐 경로를 명시.
- **이미 푸시한 커밋·PR에서 Claude 표기 지우기**: PR 본문의 `Generated with Claude Code` 줄은 PR 설명을 고쳐 지우고, 커밋 메시지의 `Co-Authored-By` 줄은 메시지만 다시 써서(트리는 그대로) 두 브랜치를 `--force-with-lease`로 다시 푸시했다. 메시지가 바뀌면 **커밋 해시가 전부 새로 바뀌므로** 다시 쓰기 전후 트리가 같은지 대조하고, 스택 PR의 아래 브랜치(`feature/#189`)부터 맞춘 뒤 위 브랜치를 올린다. 앞으로 안 붙게 하는 설정은 [[Claude-Code-AI-표기-attribution-끄기]].

## 시안 대조 방법과 결정
- dev 서버를 띄우고 **API는 가짜 응답으로 막고, 가짜 토큰을 넣어** 시안과 같은 1728×1117으로 캡처해 나란히 비교. 이 방식으로 Recent tasks 표 행 간격(행 높이 31px·행 사이 8px) 차이를 잡았다. 사이드바 색·글꼴 차이는 기존 공통 레이아웃에서 오는 것이라 범위 밖으로 두고 손대지 않음.
- **VM 시안은 Figma 호출 한도에 걸려 처음엔 못 가져와** CT 레이아웃에 이슈 항목으로 임의로 만들었고, 한도가 풀린 뒤 비교해 보니 문구·칸 이름·기본값이 꽤 달라 전부 시안에 맞게 고쳤다. 임의로 채운 부분이 있으면 PR 설명에 명시해 둔다. 한도 원리는 [[Figma-MCP-팀별-호출-한도]].
- **생성 버튼은 필수 항목을 다 채워야 활성화**(시안은 빈 폼에서도 켜진 모습이지만 의도적으로 다르게 구현).
- 시안의 ID 칸 값(108)은 **ID가 자동 배정되는 값이라 안내 문구를 유지**. 시안 오탈자 "생성되요"는 "생성돼요"로 교정.
- 생성 후 시작 체크박스 기본값은 CT 켜짐·VM 꺼짐이고, CT/VM 탭을 오가도 각자 고른 값을 유지.
- 사이드바는 `/container/create`에서도 CONTAINER 메뉴가 켜지는 구조라 수정 불필요.

## CodeRabbit 리뷰 지적 3건 (#192 머지 전 반영)
머지 전에 CodeRabbit이 코드에 단 지적을 확인해 고쳤고, 고친 뒤 빌드·린트 재통과와 리뷰 승인 유지를 확인한 다음 머지했다.
- **Swap 0 입력**: 숫자 칸의 `min`이 0보다 커서 Swap에 0을 넣으면 브라우저 기본 검증이 제출을 막았다. 0을 허용하도록 고치고 브라우저에서 제출 성공을 확인. (Claude 보충: 폼 숫자 칸은 "0이 유효한 값인가"를 `min`에서 따로 정해야 한다.)
- **CT/VM 선택 카드 키보드 접근성**: 방향키로 선택·포커스가 옮겨가게 하고, Tab은 선택된 카드에만 가도록(roving tabindex 방식) 수정.
- **Root 비밀번호 칸**: `autoComplete="new-password"`를 줘 브라우저가 저장된 비밀번호를 자동 채우지 않게 함.
