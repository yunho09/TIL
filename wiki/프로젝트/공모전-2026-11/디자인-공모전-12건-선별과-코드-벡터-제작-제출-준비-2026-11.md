## 저작권·AI 조항
- **공고 본문에 없는 양도 조항이 서식에 있을 수 있다**: 전남자치경찰은 서식1 유의사항에 "수상작 저작재산권은 시상금 지급을 대가로 주최기관에 양도". 1차 선별표의 "양도 조항 없음"이 틀렸다 → 서식 유의사항까지 읽는다.
- 피부건설: 1~3등은 저작재산권 전부 양도(상금에 대가 포함)
- 경륜·경정: 공단의 2차적 저작물 작성권, 수상작 비영리 5년 독점 사용
- 서울미래: 서약서상 수상만으로 자동 이전되지 않음. 범위는 수상 후 별도 서약서(미공개)
- AI: 서울미래는 허용하되 **활용 범위·주요 프롬프트·생성 과정 캡처·직접 수정 내용** 증빙. 코드로 그려도 그림 코드와 문안을 Claude가 썼으면 "활용"으로 신고했다.
- 서울미래는 "응모자가 직접 창작한 순수 창작물"도 요구 → AI 비중이 크면 감점·제외 위험. "본인이 직접 한 것" 칸의 초안은 사용자가 실제 한 일로 고쳐야 한다.
- 플라이하이: 바이브코딩까지 허용. 폼의 AI 도구 필수 문항에 목록에 없는 도구는 '기타'에 사실대로.

## 원문 공고를 못 여는 경우
- **dtro.or.kr**: 봇 확인용 쿠키 스크립트 때문에 curl·WebFetch는 빈 페이지 → 우회하지 않고 실제 크롬에서 열어 원문 확인(AI 금지 조항 없음)
- **kappd.or.kr**: 인증서 오류 → `curl -k`는 차단됐고 브라우저에서도 넘기지 않음. 위비티·언론 기사로 대신 확인
- **mofa.go.kr** 첨부 PDF: 리다이렉트 루프로 못 읽음(본문은 읽힘)
- 요약 사이트만 보면 서류가 빠진다: 저상버스의 저작권 동의서는 나중에 기사로 재확인해 발견
- 링커리어는 본문에 없는 제출 메일이 페이지 데이터의 지원 정보에 있었다(피부건설)
- 포스터의 QR을 해독하면 접수 구글폼 주소가 나온다(플라이하이)

## 코드 벡터 제작
- HTML/SVG를 헤드리스 크롬으로 렌더, 글꼴은 Pretendard·Noto. 기존 pycairo 파이프라인보다 빠르다고 보고 선택
- 시안 2~3개 비교 → 렌더 결과를 직접 눈으로 보고 겹침·줄바꿈 수정 → 픽셀·dpi·mm 실측
- 여러 일꾼이 동시에 렌더하지 않게 `flock` 락(`.render.lock`)으로 줄 세움
- **".ai 원본 필수"**: PDF 호환 형식을 `.ai`로 저장하고 메일·안내에 사실대로 적음. 글자 아웃라인은 `pdffonts` 0개, SVG `<text>` 0개로 확인. 일러스트레이터에서 한 번 열어 다시 저장하는 편이 확실(미실시)
- 패키지 칼선: 주최가 준 공식 PDF에서 벡터를 1:1로 뽑아 사용, 재단선·접는선을 선 모양으로 구분
- 공식 마스코트·로고는 사용 허락이 없으면 다시 그리지 않는다. 실제 SNS 로고처럼 보이는 아이콘은 일반 기호로 교체
- 캐릭터 설정은 추정하지 말고 **공식 캐릭터 페이지**를 먼저 본다: 바쿠를 "바퀴" 모티브로 추정했다가 공식 설정("천재 컴퓨터")과 달라 5개 파일을 다시 렌더
- 확인 안 된 사업명·연도는 목업 문구에 넣지 않는다(일반 문구로 교체)
- 영상 렌더: HyperFrames가 느렸던 사례는 [[공모전-AI-영상-제작-파이프라인-HyperFrames-MeloTTS-검수]]

## Gmail 초안 만들 때 (Claude in Chrome)
- 작성창 링크에는 받는 사람·제목만 넣고 본문은 직접 입력(개인정보가 URL에 남지 않게)
- **첨부 업로드가 끝나기 전에 페이지를 벗어나면 초안이 사라질 수 있다**(8.5MB에서 발생, 원인은 추정) → 업로드 완료를 기다리고 임시보관함 개수·내용 확인
- 한글 본문 입력에서 오타가 난다("컬러"→"컨러", "쭉~ 삑!"→"짭~ 샑!") → 저장 후 다시 열어 대조
- 첨부 파일이 업로드 허용 경로 밖이면 임시 복사본으로 올리고 나중에 정리
- 문의 답장이 없으면 먼저 **문의 메일이 아직 초안으로 남아 있는지** 확인(이번에 CREPET·피부건설이 그랬다)
- 본문에 "구글폼도 제출했습니다"처럼 앞선 행동을 적었으면 안내에 순서를 명시
