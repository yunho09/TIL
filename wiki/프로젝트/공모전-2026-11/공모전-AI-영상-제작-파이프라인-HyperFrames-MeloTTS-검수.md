# 공모전 AI 영상 제작 파이프라인 (HyperFrames + Figma AI + MeloTTS) 과 검수 체크

얼굴·발표가 필요 없는 AI 숏폼/예고편 공모전용으로 쓴 제작 방식과, 7편(부산 동구·세라믹·경산·SVAIFF·한센병·장기실종아동·스토리리그)을 만들며 나온 함정·검수 항목 정리. 핵심은 **"AI 이미지 + 코드 합성 영상·음향 + 로컬 TTS"** 로 유료 영상 생성 도구 없이 만든다는 것과, 제출 직전 **사실·표기·개인정보 검수**를 별도 일꾼이 맡는다는 것.

## 제작 방식
- **장면 이미지**: Figma AI(`gpt-image-2.5-flare`)로 대회당 7~12장(크레딧 한도 안). 요청 해상도(예 2048×1152, 1152×2048)와 달리 실제는 **1536×864 / 864×1536**으로 나와 1080p·세로 1080×1920에서 1.25~1.5배 확대해 쓴다 (제작 기록에 사실대로 명시).
- **합성·렌더**: HyperFrames(HeyGen 공식, HTML→영상). 필수 의존성은 `ffmpeg`(sudo 설치 필요)뿐이고 `check`로 오류 0 확인 → 렌더. 레지스트리 블록(grain-overlay·vignette·typewriter 등)은 받아서 고쳐 쓰고, 무한 CSS 애니메이션은 타임라인 트윈으로 바꿔야 렌더에서 안 깨진다.
- **타이밍표 하나(`film.py`)로 HTML·음향·SRT·포스터를 모두 재생성**하게 두면 문장 수정 시 연쇄 반영이 쉽다.
- **소리**: 효과음·배경음은 numpy로 직접 합성(음원 권리 문제 회피), 내레이션은 로컬 TTS.
- **움직이는 AI 영상(Weave 등)** 은 계정 연동·가입이 필요해 쓰지 않았다. 대신 확대·이동·전환으로 처리 → 공고가 "정지 이미지 전환·내레이션 중심은 대상 아님"이면(예: SCENE 숏드라마) 이 방식은 **불가**라 보류.
- 스킬 후보 비교(조사 결과): HyperFrames(Apache-2.0, 가장 많이 설치) · Remotion 공식(개인·3인 이하 무료, 키네틱 자막 `createTikTokStyleCaptions()`) · OpenMontage(AGPL·무거움, 보류) · video-shotcraft(16:9 제품 홍보용이라 세로 숏폼엔 부적합).

## 한국어 TTS 선택 (무료·상업 가능 여부)
- **MeloTTS-Korean**(MIT, CPU 실시간) 채택. 문장당 약 20초, 설치 3.1GB(PyTorch 포함 → 루트 여유 18GB라 `/data`에 설치).
- 설치 함정: `python-mecab-ko` 없으면 첫 실행 실패 → 추가 설치하면 해결.
- **공모전에 쓰면 안 되는 것**: Piper 한국어(CC BY-NC-SA 비상업), Coqui XTTS-v2(비상업 전용), Edge TTS(비공식 엔드포인트라 약관 위반 소지). HyperFrames 무료 음성 Kokoro는 한국어 미지원, MusicGen 가중치는 비상업 라이선스.
- 대사가 자리(창)를 넘으면 가장 빠른 속도로도 안 맞아 **문장을 줄여 다시 생성**(예: 11번 대사 앞말 삭제). 숫자는 "백십이·백팔십이"처럼 읽을 말로 풀어 쓴다. 사투리는 TTS가 못 내므로 자막으로.

## 소리 믹스: 목소리가 효과음에 묻히는 문제
- 반복해서 나온 결함: "학습 완료."(+3.1dB), "이거, 나야?"(0.4dB) 같은 핵심 대사가 효과음·드론에 묻힘. 귀로 못 들으니 **목소리 스템 RMS ÷ 배경 RMS(SNR)** 를 구간별로 재서 발견했다.
- 해결: `audio.py`에 **자동 더킹**(목소리 구간 배경 -6~-8dB, 반전 대사는 배경 비움)을 넣고 **목표 SNR +8dB 미달이면 렌더 실패**하게 가드. 결과 일반 대사 +9.5~+17.4dB.
- 한계: 검수가 전부 수치(스템 상관 0.87~1.00, 피크 -6.5~-7.5dBFS)뿐이고 **사람이 귀로 들은 확인은 없다** → 제출 전 직접 한 번 듣기 필요(특히 제주어 대사).
- 용량: 808MB → `render --crf 20`으로 327MB (PSNR 40.1dB, 눈으로 차이 없음). 대회별 용량 한도(이메일 첨부 25MB 등)는 2패스 인코딩으로 맞춘다.

## 검수 체크리스트 (별도 검수 일꾼이 확인한 항목)
- **규격**: ffprobe로 길이·해상도·코덱(H.264 High, yuv420p)·fps·AAC·피크. 공고의 자동검사 기준(90초 초과·FHD 미만·16:9 아님) 대조.
- **자막 전수 판독**: 2초 간격 프레임을 뽑아 오탈자·잘림·이미지 속 가짜 글자·손/얼굴 기형·실존 랜드마크(예: 남산타워처럼 보이는 송신탑 → 코드로 지움) 확인.
- **사실 출처**: 지명·수치를 검색으로 대조하고 출처 문서(`사실_출처.md`)에 남김. 출처가 갈리는 수치는 더 보수적으로(1,177 vs 1,242명 → "1,100명 이상"), 근거 못 찾은 문구는 빼거나 "확인됨"이라고 쓰지 않는다. 언론 수치는 "경찰 집계"로 단정하지 말고 매체를 밝힌다.
- **문서-영상 일치**: 신청서 문구가 실제 영상과 어긋난 사례("화면마다 AI 표시" → 첫 6초엔 라벨 없음). 문서 쪽을 사실에 맞게 고치고 md/hwpx/기획안을 같이 갱신.
- **블라인드 심사**: 제출 PDF에 Figma 파일 URL이 있으면 계정명이 노출될 수 있어 nodeId 번호만 남김. 로컬 경로·모델명(실제 쓴 모델과 일치 여부)도 점검.
- **AI 표기·윤리**: 엔딩에 AI 활용 표기(이미지·목소리·편집), 가상 인물 라벨은 폰에서 읽히게 크게(24→31px). 민감 주제(한센병·실종아동)는 환자·실제 아동 얼굴 없이 손·뒷모습·가상 인물만, 옛 병명·편견 조장 표현 회피.
- **서약서의 "직접 제작" 문구**: AI 사용은 신청서·영상에 밝혀 두고, 서명 전 사용자가 읽고 판단하도록 알린다.
- **Figma 교육용 요금제**: 약관상 생성물 권리는 사용자에게 있으나 상업 이용 허락 문장이 없고 교육용 자격 기준이 "비상업"이라, "상업 이용 가능 요금제" 체크 칸은 **체크하지 않고** 사실대로 적는다. 허위 신고는 실격·상금 환수 사유(SVAIFF 규정)이므로 "그냥 했다고 하면 된다"는 안 된다. 사무국 문의 메일로 보강.

## 서식(한컴독스 hwpx) 작업 함정
- 웹 한글(한컴독스)에서 편집한 내용은 **온라인에만 저장**되므로 메일에 붙이려면 `파일 → 다운로드 → hwpx`로 받아야 한다.
- 표 칸에 글자를 더하면 칸이 늘어 표가 길어지고 쪽 끝 "…귀하"가 잘리거나 쪽 고정 서명 그림이 어긋난다. 표 아래 주석 줄에 넣은 글은 쪽 여백 쪽으로 밀려 **화면·PDF에 안 나올 수 있다**(글자 수는 늘어도 안 보임). 칸 폭이 좁으면 보호자 정보처럼 긴 값은 메일 본문으로 보완.
- 화면 캡처에서 커서가 글자 옆에 겹치면 "호"가 "회"처럼 보인다 → 오타 단정 전에 **찾기·바꾸기로 문서 전체 검색**.
- 서명은 예전 서식의 서명 그림을 가져다 쓰되 새로 그리지 않는다. 개인정보(생년월일·보호자 정보)는 사용자가 정해 준 범위에서만 채운다. 서식 구조 검증은 [[공모전-양식-채움-검증-hwpx-xlsx-OnlyOffice-렌더링]] 참고(Pretendard는 OnlyOffice 렌더에서 한글이 깨져 NanumGothic 사용, 경산 PDF는 x2t가 세그폴트라 크롬으로 생성).

## 수상작 분석으로 정한 다음 영상 방향 (2026-11-23)
- **방향 전환**: 지금까지 'AI 이미지 몇 장 + 켄번스 + 자막' 방식이 많았는데, 사용자가 충남 교통안전 숏폼 「마주 보면, 보입니다」처럼 **코드로 만든 모션그래픽**(도형 픽토그램·글자 애니메이션·장면 전환·되감기 연출·합성 효과음, 46초 세로)을 괜찮다고 봐서 앞으로 기준으로 삼기로 함. 이미 완성한 영상은 지시 없이 다시 만들지 않음.
- **2025~26 국내 AI 영상 공모전 수상작 17건·심사평 7건 조사 결과** (유튜브는 직접 못 봐서 기법 중 확인 못 한 칸은 ⚠️):
  - 대상·최우수작은 거의 모두 **'틀(장치)'** 이 있다: 실사↔AI 반전, 사극 상소문·홈쇼핑 패러디, 미래의 나와 영상통화, 시간 점프.
  - **주인공 1명을 끝까지** 쓰고(지자체 마스코트 활용 사례 다수), 주최 측 사업명·랜드마크를 화면에 넣는다.
  - **음악·사운드 일체감**이 차별점. 심사평은 "기술 시연 말고 스토리 완결성", AI가 쓴 멋진 말 나열은 티가 나고, 컷마다 캐릭터가 달라지는 일관성 문제를 지적.
  - 주최 톤(밝은 결말)과 어긋나 탈락한 사례가 있고, **'AI 이미지 + 켄번스 + 자막'으로 수상한 확인 사례는 없음**.
- **체크리스트 요약**: 틀을 먼저 정하기 / 주최 단어·마스코트·랜드마크 3개 이상 / SVG 주인공 한 명을 모든 장면에(AI 이미지는 배경용) / 장면마다 움직임(정지 이미지는 2초 이내) / 첫 2초에 숫자·질문 / 공식 통계 하나 시각화 / 직접 쓴 펀치라인 / 사운드 3층(BGM 비트·동작 효과음·대사 박자) / TTS는 내레이터 1명·짧은 문장 / 지역색(사투리·실루엣) / 밝은 결말+기관 슬로건·행동 유도 / 제출 점검(규정보다 1~2초 짧게, 엔딩 AI 표기, 증빙 보관, AI 허용·저작권 조항 확인).
- **주의**: Kling 등 무료 영상 생성은 상업 이용 불가·워터마크(공식 약관 재확인 필요), 생성형 AI 작품을 아예 받지 않는 대회도 있으니 요강 먼저 확인.
- 보류했던 SCENE(정지 이미지 전환 금지 조항)은 모션그래픽 방식이면 조항에 걸리지 않아 재도전 가능.

## 새 방식 첫 적용: 경산 「네 번째 이야기꾼」 재제작 (2026-11-23)
- **틀**: AI 친구 '버들'이 주인공의 하루를 그림으로 남기는 **하루 타임라인**(상단 시계 05:50→20:30 + 우상단 '경산의 이야기꾼' 4칸이 원효·설총·일연·'나'로 채워짐). 주인공·버들은 **SVG 코드 캐릭터**라 전 장면 같은 모습, 기존 Figma AI 이미지 10장은 '버들이 그린 오늘' 그림 카드(금빛 펜이 지나가며 드러남)로 재사용 → 'AI가 그리는 순간'을 이야기 안에 넣음. 82.5초(요강 90초 이내)·1920×1080·30fps·피크 -6.9dB.
- **사운드 3층**: 오음계 가야금풍 가락+북·장구 96BPM(numpy 합성), 동작마다 효과음, 버들 대사 6문장 MeloTTS(말할 때 배경 0.45배로 더킹).
- **독립 검수에서 잡힌 버그**: GSAP `tl.fromTo(el, {opacity:1,…}, …, t)`는 **from 값이 타임라인 0초에 즉시 적용**돼 등장 시각 t 전부터 화면에 떠 있다(대추가 장면 시작부터 하늘에 떠 있음). 늦게 나타날 요소는 `opacity:0`에서 시작해 t에 1로 올리거나 `set`을 t에 둔다. 프레임 한 장씩 눈으로 봐야 보이는 유형.
- **문구 ≤ 출처 원칙 재확인**: 자막 "노래와 춤으로"의 "춤"이 출처 행(무애가를 부르며)에 없어 "노래(무애가)로"로 줄임, 고분 표지는 출처대로 "지배층의 무덤". 서류(타임라인·TTS 문장·BPM)는 build 스크립트 수치와 1:1 대조.
- **사용자 피드백**: 직접 본 결과 "너무 AI 사진 위주 — 충남 교통안전처럼 도형·글자가 움직이는 화면이 좋다(단 계속 따라 하지는 말고 참고만)". 다음 영상은 AI 이미지 비중을 더 줄이고 모션그래픽 중심으로. 새 틀을 붙여도 이미지 카드 비중이 크면 "AI 사진 위주"로 느껴진다.
- **결과: 미출품 결정**: 접수 단계에서 **보호자 본인 계정으로만 접수 가능**(학생 계정 불가)함을 알고 사용자가 포기. 완성 파일은 `/data/downloads/공모전_제출1/11-23_경산_AI미디어/`에 보관. **교훈: 대회 후보를 고를 때 접수 계정 조건(본인/보호자)을 먼저 확인**한다 — 영상까지 만든 뒤 알면 헛수고.
- 한계: 소리는 수치로만 검증(귀로 못 들음) — 이번에도 MeloTTS 자연스러움은 사람 확인 필요.
