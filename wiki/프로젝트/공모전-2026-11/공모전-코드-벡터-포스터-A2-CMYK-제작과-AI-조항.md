# 공모전 코드 벡터 포스터 — A2 CMYK 제작과 AI 조항

영암왕인문화축제 포스터 공모전에 **AI 이미지 없이 HTML/SVG 코드로 그린 벡터 포스터**를 A2·CMYK 규격으로 만들어 낸 과정과 한계. 생성형 AI 조항(원본 그대로 제출 금지·상업 이용 불가 서비스 금지·도구 명시)을 피하는 방법으로도 쓸 만하다.

## 제작 방식
- 장면 전체를 `scene.js`(공통 벡터 드로잉)로 그리고 판형별 `poster.html`·`banner.html`·`sns.html`이 비율에 맞춰 다시 배치. `render_all.sh` 한 번(약 30초)으로 전부 재렌더링.
- `export.py`: PNG → 출품 규격 JPG와 **CMYK JPG**(Pillow 기본 변환). 결과: 메인 A2 세로 4961×7016·300dpi·CMYK(6.4MB), 심사용 미리보기 RGB, 확장 시안 가로 현수막 5:1(5000×1000)·SNS 카드 1:1(2160×2160). 긴 변 3000px 이상·20MB 이하 조건 확인.
- 서체는 상업 이용 가능한 **SIL OFL**만 사용(Noto Serif CJK KR, Pretendard) — 설치 경로를 디자인 메모에 남김. 한글이 두부(□)로 깨진 곳은 4배 확대로 확인.
- 공고 필수 문구(축제명 최대 크기·주제·가변 일정 문구·주최/주관·로고용 빈 띠)를 모두 넣고, 블라인드라 **응모자 이름·소속은 포스터 어디에도 없음**. 파일명은 공고 규칙(성명_작품명) 사본을 `제출용/`에.
- 천자문 같은 고전 글자열을 쓸 때는 순서(天地玄黃 → 宇宙洪荒 → 日月盈昃…)를 검수.

## 알려진 약점·후속 작업
- **CMYK**: ICC 프로파일 없는 기본 변환이라 형광 청록·분홍이 인쇄에서 탁해질 수 있음 → 인쇄용은 프로파일로 재변환 권장.
- **수상 시 원본**: AI/PSD(레이어 유지·글자 아웃라인)를 요구하는데 지금은 HTML/SVG뿐 → 수상하면 SVG를 내보내 일러스트레이터로 옮기는 작업이 별도로 필요.
- 현수막(5:1)은 장면이 한쪽에 작게 들어가 제목 위주로 보임, 돛배·인물은 고증 없이 양식화.
- 서식에 "본인이 직접 창작한 순수 창작물" 서약이 있어, 그림 코드를 Claude가 썼다는 점을 작품 설명에 사실대로 적고 서명 여부는 사용자가 판단하게 했다. 칸이 좁으면 별첨 작품설명서 PDF.
- 연도 같은 수치(왕인 도일 405년경 → "1,600여 년 전")는 서식에 옮길 때 재확인.
