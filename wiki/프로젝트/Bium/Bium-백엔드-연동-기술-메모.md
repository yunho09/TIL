# Bium 백엔드 연동 기술 메모 — JavaMailSender·Gemini 멀티모달·식약처 영양 API·ngrok

Bium 2학기 백엔드에서 쓰기로 한 외부 연동 4가지의 동작 방식과 미리 알아둘 함정. Gemini 무료 한도와 식약처 API 세부는 세션 중 웹 검색 결과이며 자주 바뀌므로 개발 전 공식 페이지 재확인이 필요하다. 결정 배경은 [[Bium/프로젝트-현황]] 참고.

## 이메일 알림 — `JavaMailSender`
- Spring Boot 표준 방식. 의존성 `spring-boot-starter-mail` + `application.yml`의 `spring.mail.*`(host `smtp.gmail.com`, port 587, `smtp.auth`/`starttls.enable` true)를 넣으면 `JavaMailSender`가 자동 구성된다. 서비스에서 주입받아 `SimpleMailMessage`(텍스트)나 `MimeMessage`(HTML)로 `send()`.
- 매일 발송: `@Scheduled` 메서드가 임박 재료(D-3·D-Day)를 조회해 발송 로직을 호출 → 제안서 ⑥.
- **Gmail은 2단계 인증 + 앱 비밀번호**가 필요(일반 비밀번호는 안 됨). 앱 비밀번호는 GitHub에 올리지 말고 환경변수로. 개인 Gmail은 하루 발송 수 제한이 있으나 학교 프로젝트 규모면 충분.
- 메일은 서버가 SMTP로 직접 보내므로 ngrok과 무관 — 단 서버 PC가 꺼져 있으면 스케줄러도 멈춘다.

## 영수증 인식 — Gemini 멀티모달
- 멀티모달 = 텍스트와 이미지를 **한 요청**에 같이 보낼 수 있다는 뜻. 서버가 영수증 사진 + 지시문("식재료 품목명과 수량만 JSON으로")을 보내고, 응답을 JSON으로 강제하는 옵션도 있다. 별도 OCR 없이 글자 인식과 식재료 선별을 한 번에 처리. 1학기에 레시피 추천에 쓰던 같은 키·모델 계열(flash 계열도 이미지 입력 지원)을 그대로 쓸 수 있다.
- 서버 응답을 도감과 맞춰 유통기한·보관 구역을 채우고 **확인 화면**을 거쳐 등록한다. 흐릿한 사진·줄임말 품목명은 틀리게 읽을 수 있어 확인 화면이 안전장치.
- **API 키는 서버에만**: 1학기처럼 브라우저에서 직접 호출하면 키가 노출된다(1학기 한계 중 하나).
- **무료 등급**(2026 기준, 서드파티 정리 사이트 인용 — 공식 확인 전): Flash/Flash-Lite는 무료, Pro는 2026-04부터 유료 전용. 분당 약 10~15회, 하루 약 1,000~1,500회. 시연 중 동시 요청이 몰리면 분당 한도에 걸릴 수 있어 "오류 메시지 + 다시 시도"로 대응. 이미지 입력에 별도 제한이 있는지는 미확인. 무료 등급은 입력 데이터가 모델 개선에 쓰일 수 있다는 조건 → 영수증의 개인정보 주의.

## 영양 정보 — 식약처 식품영양성분 DB API
- 공공데이터포털(data.go.kr)의 **"식품의약품안전처_식품영양성분DB정보"**(REST, JSON/XML, 무료, 인증키 발급 필요). 개발 계정 호출 한도 10,000건, 운영 계정은 활용 사례 등록 시 상향. 식품명 검색 → 열량·탄수화물·단백질·지방·당류·나트륨 등(보통 100g 기준). 데이터는 원재료/가공식품/음식으로 나뉘며 냉장고 재료에는 원재료 쪽이 맞다. 같은 데이터를 식품안전나라에서도 제공.
- 설계: 도감에 재료가 추가될 때 한 번 조회해 DB에 저장하고 이후 저장값을 쓴다(응답 속도·호출 수 절감). 찾지 못하면 "정보 없음" 표시는 (Claude 보충, 팀 합의 전).
- 함정: **이름 매칭**("계란" vs "달걀") — 도감 이름과 DB 식품명을 어떻게 맞출지 정해야 한다. 개발 전 인증키 발급과 원재료 몇 개 검색 테스트 필수.

## 배포 — ngrok
- 로컬 PC에서 돌리는 프론트·백엔드를 ngrok 터널로 외부에 공개(HTTPS 자동). 비용이 들지 않아 학교 프로젝트 시연 규모에 맞고, AWS EC2/RDS 대비 서버 설정이 단순하다.
- 단점 두 가지: ① **재시작마다 주소가 바뀔 수 있음** — 무료 계정의 고정 도메인 1개를 쓰면 프론트의 API 주소·이메일 속 링크를 매번 고치지 않아도 된다. ② **서버 PC가 꺼지면 서비스와 스케줄러(이메일 알림)가 멈춤** — 시연 전 서버 PC 가동과 메일 발송을 점검.
