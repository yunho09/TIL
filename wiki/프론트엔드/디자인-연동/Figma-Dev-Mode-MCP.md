# Figma Dev Mode MCP

Figma 파일을 Claude가 직접 읽어 디자인 스펙(레이아웃·색상·타이포)을 추출할 수 있게 해주는 MCP 서버(`127.0.0.1:3845`에 로컬로 뜬다). 두 가지 전제 조건이 안 맞으면 조용히 실패하는 게 아니라 명확한 에러를 낸다.

## 동작 조건

- **Figma 데스크톱 앱**에 대상 파일이 열려 있어야 한다. 웹 브라우저 탭에 열려 있는 것과는 무관하다 — MCP는 데스크톱 앱의 플러그인 API를 통해 씬 그래프에 접근한다.
- 열려 있어도 파일이 **view-only**(편집 권한 없음, 예: 팀 소속 인증이 안 된 상태) 상태면 `get_design_context` 같은 씬 그래프 조회 API가 `Figma Plugin API not available — ensure a file is open and fully loaded` 에러를 낸다.

## view-only일 때의 대안

- `get_screenshot`은 view-only에서도 `capturePage` 방식으로 폴백 동작해서 화면 캡처 자체는 가능하다.
- 다만 레이어별 정확한 속성(정확한 px 수치, 색상 hex, 텍스트 스타일 이름)은 못 가져오므로, 캡처된 스크린샷을 **픽셀 단위로 직접 계측**해서 수치를 역산해야 한다. 이때:
  - 프레임 폭이 Figma 우측 패널에 표시돼 있으면 그 값으로 캡처 이미지의 스케일(px/design-px)을 정확히 잡을 수 있다.
  - 폰트 크기는 감으로 추정하지 말고, 후보 크기별로 실제 폰트를 렌더링해 잉크 바운딩박스 크기를 계측값과 대조하면 정확히 특정할 수 있다.
  - 그래도 ±1~2px 오차는 남을 수 있어, 편집 권한이 풀리면 인스펙터 값으로 재검증하는 게 좋다.

관련: [[JOBIS-FE-V2/프로젝트-현황]] — 이 조건을 실제로 겪은 사례(학생 지원하기 화면 퍼블리싱).

## 에셋(이미지) export 함정 3가지

Figma 시안의 이미지를 코드에 그대로 박아 넣을 때(하드코딩 배너 등), 어느 도구로 뽑느냐에 따라 못 쓰는 파일이 나올 수 있다.

- **`get_design_context`가 반환하는 이미지가 전 픽셀 투명(alpha 0)할 수 있다** — 노드 자체는 시안에 정상적으로 보여도, 이 API가 내려주는 첨부 PNG가 빈 파일인 경우가 있었다(1024×1024 전체 alpha=0). 화면엔 아무것도 안 보이는데 콘솔 에러도 없어서, 이미지 자체가 깨졌다는 걸 눈으로 렌더링해서 확인해야 알아챈다.
- **`download_assets`의 `export`는 부모 프레임에 잘린 합성 렌더일 수 있다** — 노드 하나만 export해도 부모 프레임 배경까지 같이 합성되어 잘린 결과(alpha 전부 255, 배경 포함)가 나올 수 있다. 투명 배경의 개별 아이콘/일러스트가 필요하면 이 export는 못 쓴다.
- **원본 소스 이미지는 `rawImages`로 받아야 한다** — 위 두 경로가 막히면 `download_assets`가 제공하는 `rawImages`(레이어가 참조하는 원본 이미지 파일)를 직접 받아서 필요한 크기로 리사이즈해 쓰는 게 확실하다.

렌더 검증 시엔 시안 좌표(위치·크기)를 그대로 상수로 고정하고 `auto`류 자동 배치에 의존하지 않는 게, 시안과 픽셀 단위로 대조하기 쉽다.

관련: [[JOBIS-FE-V2/프로젝트-현황]] — 학생 앱 홈 배너를 Figma 시안대로 하드코딩할 때 위 3가지를 순서대로 다 겪은 사례.

## 파일 목록·이름 검색 불가, 링크 필요 (2026-11-11 추가)
- claude.ai Figma MCP에는 팀·프로젝트의 파일 목록을 보거나 이름으로 검색하는 도구가 없고 모든 도구가 파일 키를 받는다(`whoami`로 팀·좌석만 확인 가능). 파일을 열려면 **Share → Copy link** URL이 필요하고, 특정 프레임은 그 프레임을 선택한 채 복사해 `node-id`를 포함시킨다(`node-id=0-1` → `0:1`).
- 자동 생성 프레임을 신뢰하지 말 것: 프레임 이름("3 새 비밀번호")과 실제 내용(학번·이름 폼)이 다르거나, 폼 인스턴스 안 텍스트가 메타데이터에 안 나와 스크린샷으로 읽어야 하거나, 높이 1px 숨은 프레임·`LINK CAPTION` 숨김 레이어가 있었다. 사례: [[xquare-openapi-frontend/프로젝트-현황]].
- SVG를 `<g>` 묶음째 가져오면 안의 선이 제자리를 잃을 수 있어 묶음을 풀어 넣는다.

## 일부 쪽만 PDF로 내보내기 (2026-11-11 추가)
- Figma "프레임을 PDF로 내보내기"는 그 페이지의 **보이는 프레임 전부**를 내보낸다. 빼고 싶은 쪽(예: 초안 3쪽)은 **잠깐 숨기고 내보낸 뒤 다시 보이게** 돌려놓는다.
- 바닥글이 `N / 8`처럼 총 쪽수를 박고 있으면 5쪽본에서 어색하므로 `N / 5`로 바꿔 내보내고 원복한다. 8쪽본은 바닥글 그대로 내보내면 된다.
- 기존 PDF가 Chrome 인쇄본이고 HTML 원본이 없으면 Figma 재내보내기의 쪽 크기가 달라진다(A4 595×842pt → 794×1123pt, 인쇄 시 A4로 축소). 이전 파일은 덮어쓰지 말고 날짜·구성별로 이름을 구분해 둔다.
- Plugin API 텍스트 수정은 폰트 로드 → `await` → 변경 → 노드 ID 반환 순서. 숫자 자릿수가 같으면 레이아웃이 안 밀려, 줄바꿈이 바뀐 곳만 스크린샷으로 확인하면 충분했다.
