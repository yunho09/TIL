# 표 컨테이너와 표 자체에 동시에 height를 주면 행 높이가 늘어나는 버그

바깥 프레임뿐 아니라 `<table>`(또는 `.tbl`) 자체에도 고정 height를 주면, 행 수가 적을 때 남는 높이가 행에 분배되어 행이 비정상적으로 커 보이는 CSS 버그. 헤더에서 한참 아래 뜬 것처럼 보이거나 셀 내용이 표 한가운데로 밀려 보이는 증상으로 나타난다.

## 원인
- 바깥 프레임(`.krds-table-wrap`)에 `height: 539px`를 준 것과 별개로, 표 자체(`.tbl`)에도 같은 `height: 539px`를 중복으로 줬다.
- 표에 height를 지정하면 브라우저가 남는 높이를 행에 나눠 분배한다. 행이 1개뿐이면 그 한 행이 500px 가까이 늘어난다.
- `td { vertical-align: middle }`이 걸려 있으면 늘어난 행 안에서 글자가 세로 중앙(표 한가운데)으로 밀려 보인다.

## 해결
표의 `height`만 제거한다. 바깥 프레임이 이미 전체 높이를 고정하므로 페이지네이션 위치는 그대로 유지되고, 행은 `td { height: 50px }` 같은 개별 행 높이 규칙을 따라 헤더 바로 아래부터 쌓인다.

## 함정
같은 패턴(바깥 프레임 height + 표 자체 height 중복)이 다른 표 컴포넌트에도 복사돼 있을 수 있다. 데이터가 적게 들어올 때만 증상이 드러나므로, 평소 행이 많은 화면에서는 안 보이다가 필터링 등으로 결과가 1~2건이 되는 순간 나타난다.
