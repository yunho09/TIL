# 도로명주소 검색 API 신청 (business.juso.go.kr)

행정안전부 **주소기반산업지원서비스**(business.juso.go.kr)가 제공하는 도로명주소 검색 API의 승인키(`confmKey`) 발급 절차. 사이트가 SPA(`/jst/*`, `/jsm/*`)로 개편되어 예전에 돌던 `/addrlink/openApi/*` 경로는 전부 404이므로 아래 경로만 유효하다(신청 화면의 프론트엔드 코드를 직접 열어 확인한 경로).

## 신청 절차
1. **https://business.juso.go.kr** 회원가입 후 로그인 (신청은 로그인 상태여야 함).
2. 메뉴 **주소정보 API 연계 → API 신청하기 → API 목록** → 우리가 쓰는 건 **검색 API / 도로명주소** (`/jst/jstRoadNmAddrApiSearch`). **팝업 API와는 다른 API**라 승인키를 공유하지 못한다 — API별로 따로 신청해야 한다.
3. 페이지 하단 파란 버튼 **`OPEN API 신청하기`**로 진입. 신청서 URL(`/jst/jstAddressApiApplicationWrite`)을 직접 입력하면 어떤 API인지 식별하는 `uniqKey` 쿼리가 없어 목록으로 튕긴다 — 반드시 버튼으로 들어가야 한다.
4. 신청서 입력:

   | 항목 | 필수 | 값 |
   |---|:---:|---|
   | 시스템 명 | ✅ | 자유 입력 |
   | URL(IP) | ✅ | 서비스 도메인, 50자 이내. 로컬 개발용은 `localhost` |
   | 시스템개요 | — | 100자 이내 |
   | 서비스망 | ✅ | 인터넷 망 (행정망 아님) |
   | 서비스 용도 | ✅ | **운영**(`ope`) 또는 **개발**(`dev`, 본인인증 없이 즉시 발급) |

   검색 API는 신청인 정보·활용목적·신청사유를 받지 않는다(좌표제공/지도제공 API 전용 항목).
5. 제출 확인창(`신청 후 승인키 확인바랍니다`) 이후:
   - **개발** 선택 → 본인인증 없이 바로 접수, **API 신청 상세보기 화면에서 승인키 즉시 표시**.
   - **운영** 선택 → 휴대폰/아이핀 본인인증 후 접수, 마이페이지에서 확인 (정확한 표시 위치는 확인 못함 — `/jsm/jsmApiList`는 운영 흐름이 제출 후 리다이렉트하는 곳이라는 것만 확인됨. 이 라우트의 페이지 타이틀은 "나의 문의글"이라 승인키 목록 화면이라고 단정할 수 없음).
6. 승인키는 **시스템(URL) 단위**로 발급된다. 로컬 개발용(`localhost`)과 배포용(실제 도메인)은 따로 신청해야 한다. 시스템이 여러 개면 IP/URL 목록을 엑셀로 첨부해 일괄 발급받을 수 있다(신청서에서 양식 다운로드 제공). 행정망 운영 시스템은 1588-0061(7번 도로명주소)로 별도 문의.

## 사용법
- 요청 파라미터는 `confmKey`. 실제 호출은 `addrLinkApiJsonp.do`에 JSONP로 요청.
- 응답의 `errorCode`로 승인 상태 확인: `"0"`/`"정상"`이면 정상 동작, 미승인이면 `E0005` 등 에러 코드가 온다.

## 확인 못 한 것
- 개발용(`dev`) 승인키의 유효기간. 발급 화면에 표시되지만 문서로는 확인하지 못함 — **운영 배포 전에는 반드시 배포 도메인으로 운영(`ope`)용 키를 별도 신청**해야 한다.

## 이 키는 비밀이 아니다
프론트가 브라우저에서 직접 JSONP로 호출하는 구조라, 키가 [[Vite-빌드타임-환경변수-인라인|빌드된 JS 번들]]에 그대로 노출된다. juso가 승인키를 URL/시스템 단위로 제한하는 이유도 그래서다. 숨기려면 백엔드에 프록시를 둬야 한다.
