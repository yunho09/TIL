# 카카오톡(Wine) 받은 파일을 Downloads로, 폴더 열기를 우분투 파일 앱으로

Wine 카카오톡은 받은 파일을 `~/문서/카카오톡 받은 파일`에 저장해 왔다. 이 폴더를 `~/Downloads`로 가는 링크로 바꿔 받은 파일이 Downloads에 바로 모이게 했고, Wine의 폴더 열기는 레지스트리를 바꿔 우분투 파일 앱(`xdg-open`)으로 넘겼다.

## 받은 파일 → Downloads
- `~/문서/카카오톡 받은 파일`을 **`~/Downloads`를 가리키는 링크**로 교체. 카카오톡 쪽 저장 경로는 그대로 두고 실제 저장 위치만 바뀐다.
- 기존 폴더에 있던 파일 8개는 겹치는 이름이 없는 것을 확인하고 `~/Downloads`로 옮겼다.
- 8월 이전 파일이 든 `~/문서/KakaoTalk Downloads` 폴더는 별개라 건드리지 않았다.
- `~/Downloads` 자체의 구성은 [[Downloads-폴더-영문-통합-XDG와-최신순-정렬]] 참고.

## 폴더 열기 → 우분투 파일 앱
- Wine이 폴더를 열 때 쓰는 창을 레지스트리 수정으로 `xdg-open`에 넘겼다.
- **원래 설정 백업:** `~/.wine-kakaotalk/folder-class-backup-20261126.reg`
- Wine으로 직접 폴더를 열면 파일 앱이 뜨는 것까지 확인.

## 미확인 (2026-11-26)
- **카카오톡 버튼으로는 아직 확인하지 못했다.**
- 버튼을 눌렀을 때 여전히 Wine 창이 뜨면, 카카오톡이 Wine 탐색기를 **직접 실행**하는 것이라 레지스트리 방식으로는 안 되고 다른 방법이 필요하다.
