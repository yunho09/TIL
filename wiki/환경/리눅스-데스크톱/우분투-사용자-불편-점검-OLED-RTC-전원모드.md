# 우분투 사용자 불편 점검 (OLED 절전·윈도우 시계·전원 모드)

Galaxy Book5 Ubuntu 26.04를 "최적화·사용자 불친절한 부분" 관점에서 점검한 결과. 부팅 18.8초, 디스크·메모리 여유, 실패 서비스·크래시 없음으로 큰 문제는 없었고, 설정 몇 개가 손해였다. 개별 원인은 관련 페이지로 연결한다.

## 적용한 것
- **화면 끄기 '안 함' → 10분**: 패널이 삼성 OLED(ATNA60CL07)라 고정 UI(상단 바·독) 번인과 배터리 소모 위험. 예전에 '안 함'으로 둔 건 Claude 작업 중 절전으로 멈춰서였는데 지금은 [[Claude-작업-중-화면-절전-유지-훅과-GNOME-억제자]]가 작업 중 화면을 켜 두므로 안전. 화면이 꺼질 때 잠금도 같이 걸림.
- **Vitals 팬 항목 끔**: [[Vitals-확장-상단바-시스템-모니터]] 참고.
- **파일 앱 폴더 먼저 정렬**: [[Nautilus-폴더-먼저-정렬-끄기와-Homebrew-gsettings-함정]] 참고.
- **Ctrl+Alt+T를 Ghostty로**: 터미널 선택 설정이 Ghostty를 가리키게 해 `.sh` 실행 터미널도 Ghostty가 됨.
- 자동 시작 `ubuntu-report` 끔(`snap userd`는 실패하지만 남김), 확장 폴더에 잘못 생긴 `.omc` 폴더 삭제(로드 오류 원인).

## 윈도우 다녀오면 시계가 9시간 앞섬 (직접 해결 대기)
- 증상: 부팅 직후 시계가 20:17(실제 11:17)로 시작, 인터넷 시간 동기화 후에야 복구. 인터넷이 없으면 틀린 시간 유지.
- 원인: 윈도우는 하드웨어 시계(RTC)에 **현지 시간(KST)** 을 저장하고 우분투는 **UTC**로 읽음 → +9시간.
- 해결: 윈도우 레지스트리에 `RealTimeIsUniversal=1`(윈도우도 UTC로 저장). 윈도우로 부팅했을 때 단계별로 안내하기로 함(미적용).

## 전원 모드 측정 (배터리, 30초씩)
| 모드 | 소비 전력 | 측정 중 부하 |
|---|---|---|
| 성능 | 15.2W | 1.5 |
| 균형 | 11.6W | 3.2 |
- 균형이 약 24% 적게 소비(부하는 오히려 높았음), 배터리 사용 시간 약 1시간 연장 추정(짧은 측정이라 오차 큼). '성능'은 사용자가 유지하기로 한 설정이라 변경 안 함. 배터리일 때만 자동 '균형' 전환은 제안만 한 상태.

## 보류·미해결
- **배터리 충전 상한(80%)**: 삼성 드라이버가 지원해 가능하나 아직 100% 그대로(127사이클·용량 100%라 예방 차원).
- **gnome-shell 보안 업데이트(50.1-0ubuntu1.5) 밀림**: 7월에 낮은 버전으로 되돌리고 업데이트를 막아 둠, 이유 기록 없음 → 이유를 기억해야 해제 여부 결정.
- 제안만 하고 안 한 것: Tiling Assistant 확장(1/4 타일링·남은 칸 채우기), 파일 앱 우클릭 "Ghostty에서 열기"(패키지 설치·관리자 암호 필요). 윈도우 전환 버튼은 만들지 않기로 함.
- 백그라운드 점검: Clawd(CPU ~30%)는 9월 결정대로 유지, snap 옛 버전 없음, 펌웨어 업데이트 없음.
