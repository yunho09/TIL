# GPIO 기초

**General Purpose Input/Output** — 범용 입출력 핀. 라즈베리파이 보드 가장자리의 **40핀 헤더**가 그것이다. 소프트웨어에서 각 핀의 전압을 직접 켜고 끄거나 읽을 수 있어서, 별도 회로 없이 LED·버튼·센서를 붙일 수 있다.

## 핀이 하는 일

| 모드 | 동작 | 예 |
|---|---|---|
| 출력 | 3.3V를 내보내거나(HIGH) 0V로 만든다(LOW) | LED 켜기 |
| 입력 | 지금 전압이 걸려 있는지 읽는다 | 버튼 눌림 감지 |

`LED(17).on()`은 결국 **"GPIO17 핀에 3.3V를 걸어라"** 는 뜻이다. 그 전압이 점퍼선 → LED → 저항 → GND로 흐르면서 LED가 켜진다. 저항은 LED에 과전류가 흐르지 않게 제한하는 역할이다.

**출력은 3.3V다.** 5V가 아니다. 5V 로직을 쓰는 부품을 입력으로 직접 물리면 파이가 손상될 수 있다.

## PWM — 밝기를 만드는 방법

핀은 켜짐/꺼짐 두 가지뿐이라 "절반 전압"을 낼 수 없다. 대신 **아주 빠르게 켰다 껐다 반복**해서 평균을 낮춘다. 절반 시간만 켜면 사람 눈에는 절반 밝기로 보인다. 이것이 PWM(Pulse Width Modulation, 펄스 폭 변조)이다.

gpiozero에서는 `PWMLED`가 이걸 담당한다 → [[gpiozero-PWMLED-밝기-제어]]

## 핀 번호 체계가 두 가지다

**BCM 번호**(GPIO17 등)와 **물리 핀 자리 번호**(헤더에서 몇 번째 구멍인지)는 다른 체계다. 코드에 쓰는 건 BCM이다.

```
GPIO17 → 물리 11번 자리
GPIO27 → 물리 13번 자리     (물리 13번 ≠ GPIO13)
GPIO22 → 물리 15번 자리
```

이 혼동이 "코드는 도는데 LED가 안 켜지는" 가장 흔한 원인이다 → [[gpiozero-GPIO-배선-확인]]

## 핀은 프로그램끼리 공유되지 않는다

한 핀은 **한 프로세스만 점유**한다. 같은 핀을 쓰는 프로그램을 두 개 띄우면 나중 것이 `GPIO busy`로 죽는다. 프로그램 여러 개를 동시에 돌리는 것 자체는 문제없고, 핀이 겹칠 때만 충돌한다.
