# Notion MCP — Notion식 마크다운 작성 규칙과 긴 페이지 분할 업로드

Notion MCP(`notion-create-pages`, `notion-update-page`)로 긴 문서를 올릴 때 지킨 **작성 규칙과 함정** 정리. 특수문자 이스케이프, 토글·표 문법, 굵게(`**`) 닫힘 문제, 긴 본문을 섹션 경계에서 나눠 올리는 방법을 다룬다. (Claude 세션 관찰 기준이며 Notion 공식 스펙 확인은 아님)

## 문법 규칙
- 이스케이프가 필요한 문자: `[ ] < > ~ | { } $` (예: `TEAM\[YOT\]`). 범위 표기의 `~`는 `–`로 바꿔 쓰면 안전.
- 토글 제목: `# 제목 {toggle="true"}` 아래 자식은 **탭 들여쓰기**.
- 블록 태그: `<callout>`, `<columns>`, `<table header-row="true">`, `<table_of_contents/>`.
- 페이지 제목/아이콘은 본문 첫머리의 `TITLE:` / `ICON:` 줄 관례로 따로 두고, 제목에 이모지를 중복하지 않는다.

## 굵게 닫힘 함정
- `"**X**"`는 정상, `**"X"**한`처럼 **닫는 `**` 앞이 따옴표이고 뒤에 한글이 바로 붙으면** CommonMark 규칙상 안 닫혀 `**`가 그대로 보일 수 있다.
- 고치는 법: 닫는 `**` 뒤에 공백을 넣거나, 따옴표를 `**` 바깥으로 뺀다.
- 올리기 전 grep/스크립트로 "닫는 `**` 바로 뒤 한글"을 검사해 두면 좋다.

## 빈칸 `___`
- `___ ms` 같은 빈칸은 Notion이 `***`로 바꿔 보여준다 → 근본 대처는 [[Notion-MCP-update_content-빈칸-별표-깨짐]]. 이 세션에서는 최종적으로 **"(빈칸)"** 같은 문구로 대체했다.

## 긴 페이지 분할 업로드
- 한 번에 올릴 본문은 **약 12,000자 이내**로, `#` 제목(섹션) 경계에서 나눈다. 24k자짜리 초안을 통째로 한 호출에 넣으려던 시도가 실패하거나 중간에 끊긴 사례가 있었다 (Claude 보충: 원인은 호출 크기 한도 추정).
- 올린 뒤에는 각 페이지를 fetch해 **제목 목록과 마지막 5줄**이 로컬 초안과 같은지 대조해 잘림을 확인한다.
- 여러 하위 페이지를 올릴 때는 상위 페이지 아래 순서대로 만들고, 부모 페이지 끝에 "더 자세히 보기" 섹션으로 링크를 모은다.
- 번호 목록이 코드 블록 뒤에서 1부터 다시 시작해 보이는 현상이 있었으나 가져온 결과의 표기인지는 미확인.

## 여러 출처로 쓴 문서의 사실검증 운영 팁
- 초안은 에이전트가 쓰고, **별도 검증 에이전트가 원본 보고서와 숫자·날짜·인용을 대조**한 뒤 올리면 오류가 많이 걸러졌다 (한 번에 22건 정정).
- 자주 걸린 유형: 따옴표 안에 의역·맞춤법 교정이 들어감(인용은 원문 그대로), 출처에 없는 비교 표현("학생 평균 이상"), 출처끼리 수치가 다른 경우(두 값과 기준을 병기), 사적인 일기·식별 정보 노출.
- 사람에 대한 문서는 타인 실명은 역할로, 학번·연락처·토큰은 뺀다.
