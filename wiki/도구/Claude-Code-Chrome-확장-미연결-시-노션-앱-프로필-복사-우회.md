# Claude Code — Chrome 확장 미연결 시 노션 앱 프로필 복사 우회

Claude Code 세션에 `mcp__claude-in-chrome__*` 도구가 붙어 있지 않으면 크롬이 켜져 있고 확장이 설치돼 있어도 크롬을 조작할 수 없다. 이때 노션 커넥터는 다른 워크스페이스 게스트 페이지를 404로 돌려주므로, 로그인된 노션 앱 프로필을 복사해 별도 크롬으로 여는 우회를 썼다. (Claude 세션 관찰)

## 증상과 연결 방법
- 도구 검색(ToolSearch)에 chrome 도구가 안 나오면 세션 안에서 에이전트가 직접 붙일 수 없다.
- 해결: 입력창에 **`/chrome`**(스킬 이름 `/anthropic-skills:chrome-browser`가 아님), 그래도 안 되면 터미널에서 **`claude --chrome`**으로 새로 시작. 세션이 Orca 같은 래퍼 안에서 돌면 시작 시 크롬 연결이 빠졌을 수 있다.

## 노션 커넥터 한계
- 노션 커넥터는 내 워크스페이스만 본다. 다른 팀 워크스페이스(예: jej)에 **게스트**로 있는 페이지는 직접 열면 **404**.
- 같은 이유로 팀 노션의 일지·회고록은 커넥터로 읽거나 고칠 수 없다.

## 우회: 로그인된 프로필을 복사해 별도 크롬 띄우기
- 노션 앱(또는 크롬)에 로그인된 프로필 디렉터리를 **임시 위치로 복사**해, 그 프로필로 별도 크롬을 띄워 페이지를 열고 읽기·수정한다.
- 끝나면 임시 크롬을 끄고 복사본(로그인 정보 포함)을 **반드시 삭제**한다. 크롬이 종료 중에도 파일을 쓰므로 첫 삭제는 실패할 수 있어 잠시 뒤 재시도.
- 노션 편집 시 글머리 기호가 자동으로 붙어 "• •"처럼 겹칠 수 있다. 저장 후 페이지를 **다시 열어 반영 여부를 확인**한다.

## 운영 교훈
- "확인하고 수정할 거 수정해줘" 같은 모호한 요청에서 **남의 칸·팀 문서를 넓게 고치면 안 된다**. 이번에는 사용자가 원한 것이 회고록 수정이 아니라 *자기 보고서만 쓰는 것*이어서, 고친 4곳을 원문 그대로 되돌렸다. 수정 대상은 명시된 본인 몫으로 좁히고, 되돌릴 원문을 먼저 기록해 둔다.
