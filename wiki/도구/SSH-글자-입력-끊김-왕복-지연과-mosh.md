# SSH 글자 입력 끊김 — 왕복 지연과 mosh

SSH 터미널에서 글자를 칠 때 끊기는 느낌은 어느 정도 정상이다. SSH는 키를 칠 때마다 서버로 보내고 서버가 돌려준 글자를 그제야 화면에 그리므로, 키 하나가 화면에 뜨기까지 **왕복 시간(RTT) 한 번**이 걸린다. 느린 건 내 컴퓨터가 아니라 서버까지 가는 길이다.

## 체감 기준
- 왕복 **30ms 이하**: 거의 못 느낌
- **50~100ms 이상**이거나 값이 **들쭉날쭉**: "치는데 끊기는" 느낌
- 집 Wi-Fi(공유기까지 1~2ms)는 원인이 아니다. 서버까지의 `ping` 값을 봐야 한다.
- 한글 조합(IME)은 내 컴퓨터에서 일어나므로 이 지연과 무관하다.

## 줄이는 방법
1. **mosh**: 친 글자를 로컬 화면에 먼저 예측해 그려서 거의 즉시 보인다. 단, 서버에도 mosh 설치와 UDP 포트(기본 60000~61000대) 개방이 필요하다. 22번이 아닌 포트로 SSH를 여는 학교·플랫폼형 서버는 안 될 가능성이 높다.
2. **VS Code Remote-SSH**: 편집은 로컬에서 하고 저장할 때만 전송하므로 코드 입력은 안 끊긴다. 통합 터미널은 그대로 느리다.
3. 긴 명령은 로컬 터미널에서 다 쓴 뒤 붙여넣기: 한 번에 전송돼 덜 답답하다.
