# Claude Code 학습용 Learning 출력 스타일과 설명 스킬

기술 이해 깊이를 늘릴 때 쓸 수 있는 Claude Code 기능 정리. **Learning 출력 스타일**은 한 세션에만 켤 수 있고, 설명 스킬들은 개념 수업보다 **특정 코드베이스 설명**에 맞다.

## Learning 출력 스타일

- 이 세션에만 켜진다(다른 세션 영향 없음). 켤 때 설정 확인 창이 뜨고 **다음 답부터** 적용
- 끄기: 세션 제목 줄 메뉴의 **Output style**
- 설명 중간에 `★ Insight` 상자(핵심 2~3개)가 붙는다
- 원래 용도는 코딩 중 `TODO(human)` 빈칸을 남겨 직접 짜게 하는 것 → 개념 수업에는 효과가 크지 않을 수 있다
- 저장소 수정 금지 상황이면 빈칸 대신 채팅 안 문제로 낸다

## OMC 설명 스킬

| 스킬 | 하는 일 |
|---|---|
| `/oh-my-claudecode:teach` | 코드가 어떻게·왜 그런지 설명, 예측 질문 |
| `/oh-my-claudecode:how` | 코드 영역을 겉에서 속으로 정리 |
| `/oh-my-claudecode:why` | git 기록·커밋·이슈로 이유 추적, 증거/추측 구분 |
| `/oh-my-claudecode:bro` | 직전 설명을 쉬운 말로 |

- 추천 흐름: 개념은 조각 단위 수업 → 주제를 끝내면 `teach`·`why`로 실제 코드에 붙여 재확인
- `teach`·`how`는 저장소를 넓게 읽으므로 **해당 저장소 폴더에서 세션을 여는** 편이 낫다

## 외부 학습 플러그인 후보 (설치·검증 안 함, 2026-11-26)

- **learn** — `/explain`·`/why`·`/quiz`·`/teach`. 세션 시작 훅이 있어 모든 세션에 끼어들 수 있음
- **Study Desk** — 내 자료로만 문제·모의시험·채점
- **Ágora Learning** — 소크라테스식 질문·간격 반복. 훅 없이 독립 동작
- **learn-with-claude** (GitHub) — 효과 검증 기록 없음, 받기 전에 내용 확인 필요
- 스킬·플러그인은 Claude의 행동 규칙을 바꾸고 훅이 자동 실행될 수 있어, 세션에서는 **사용자가 직접 골라 설치**하기로 했다
- 이미 OMC·superpowers 훅이 많아 훅 있는 플러그인을 더 얹으면 충돌 가능

## 확인 안 된 것

- 플러그인은 설정 파일 단위(전역/프로젝트)로 켜는 것으로 알고 있으나, "이 세션 하나만" 켜는 방법은 모른다
