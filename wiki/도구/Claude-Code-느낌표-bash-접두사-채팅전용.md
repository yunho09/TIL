# Claude Code 느낌표(!) bash 접두사는 채팅 입력 전용

Claude Code 세션에서 **채팅 메시지의 맨 앞**에 `!`를 붙이면, Claude를 거치지 않고 그 메시지 전체를 사람이 직접 승인한 bash 명령으로 곧바로 실행해준다. 게이트처럼 "AI가 대신 실행하면 안 되고 사람이 직접 돌려야 하는" 명령을 안내할 때 유용하다.

## 함정

이 `!` 접두사는 **채팅 입력창 전용**이다. 안내받은 `!command` 문자열을 실제 bash-input(터미널) 세션에 그대로 붙여넣으면 `!`가 그냥 셸로 전달되고, 셸은 `!node` 같은 이름의 명령을 찾다가 다음처럼 죽는다.

```
(eval):3: command not found: !node
```

여러 줄을 붙여넣을 때 일부 줄에만 `!`를 섞어도 마찬가지다 — `!` 없는 줄만 정상 실행되고 나머지는 전부 이 에러로 실패한다.

## 규칙

- 사람이 대신 실행해야 하는 명령을 여러 개 안내할 땐, "채팅창에 `!`를 붙여 보내라"는 것인지 "터미널에 그냥 붙여넣으라"는 것인지 **명확히 구분**해서 안내한다.
- 터미널(bash-input)에 붙여넣을 스크립트에는 `!`를 넣지 않는다 — 일반 멀티라인 bash 스크립트 그대로 준다.
- 채팅으로 하나씩 사람이 실행시키게 하려면 명령마다 별도 메시지로, 각각 맨 앞에 `!`를 붙여 보내게 안내한다.
