# Claude Code 서브에이전트 남발과 토큰 소모

컨트랙트·구현계획 작성 같은 작업을 여러 팀 에이전트로 병렬 fan-out(최대 4개 동시)했다가 토큰을 과다 소모한 사례. 이후로는 에이전트 없이 직접, 작은 묶음 단위로 순차 작업하는 방식으로 전환했다.

## 교훈

반복적이거나 탐색적인 소작업(문서 몇 줄 수정, 시나리오 확정 등)까지 매번 서브에이전트로 fan-out하면 토큰 비용이 급증한다. 작업 단위가 작고 순차적일 때는 서브에이전트를 거치지 않고 직접 처리하는 편이 낫다.

서브에이전트 fan-out은 각 작업이 **독립적이고**(서로 결과를 기다릴 필요 없음) **덩어리가 커서**(단순 조회/한 줄 수정이 아님) 병렬화 이득이 토큰 오버헤드를 상회할 때만 값어치를 한다.
