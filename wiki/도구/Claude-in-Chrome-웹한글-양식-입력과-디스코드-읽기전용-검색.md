# Claude in Chrome — 웹한글 양식 입력과 디스코드 읽기 전용 검색

Claude in Chrome(브라우저 자동화)으로 한컴독스 웹한글 양식을 채우고, 로그인된 디스코드에서 본인 메시지를 **읽기만** 한 세션에서 얻은 요령. 둘 다 레이아웃이 입력에 따라 밀리거나 속도 제한이 있어 순서와 확인 절차가 중요하다. (Claude 세션 관찰)

## 웹한글(한컴독스) 양식 입력
- 문서 링크(`webhwp...docId`)를 자동화 탭에서 직접 열면 실패 → **한컴독스 홈에서 문서를 열어** 들어갔다.
- 칸 내용이 길어 줄이 넘어가면 표가 늘어나 **아래 칸 위치가 밀린다** → **아래쪽 표/칸부터 위로** 채운다.
- Backspace를 빠르게 연타하면 입력이 누락됨 → **드래그로 선택 후 Delete**.
- 엉뚱한 칸(제목 셀 등)에 입력했으면 `Ctrl+Z`로 되돌린다.
- 칸 폭이 좁으면 입력이 두 줄로 넘어가므로 문구를 줄인다 (예: 지원분야, 학교명 축약).
- 자소서 칸은 글 길이에 맞춰 늘어나 **쪽수가 늘 수 있다** (2쪽 양식이 3쪽) → 쪽수 제한이 있으면 줄여야 함.
- 이름·생년월일·주소·연락처·사진 같은 개인정보 칸은 사용자가 직접 입력하게 비워 둔다.
- 끝나면 "저장되었습니다" 표시를 확인. 표 자체가 쪽을 못 넘는 문제는 [[웹한글-표-글자처럼-취급-빈-첫쪽]].

### 웹한글 편집 요령 추가 (2026-11-09, canvas 렌더라 스크린샷·확대로 확인)
- **칸 안 Ctrl+A는 그 칸 글자만 선택** → 그대로 타이핑하면 교체. Return은 문단 분할. 표 안 Ctrl+Return은 아래에 행 추가, **표 밖에서는 쪽 나누기**.
- **문장 수정은 찾아 바꾸기(문서 전체 → 모두 바꾸기)** 가 가장 믿을 만했다. 바꾼 칸을 확대해서 확인.
- **Ctrl+B는 불안정** → 줄을 Home + Shift+End(또는 Shift+클릭)로 선택 후 **도구 모음 굵게 버튼**. 새 행은 앞 칸 굵기를 상속하므로 칸 전체를 굵기 해제한 뒤 필요한 글자만 굵게.
- 글꼴 칸은 타이핑으로 못 바꿈 → **모양 복사**(글자+문단 둘 다)로 다른 칸 서식을 복사해 적용. 바탕체로 들어간 칸을 굴림으로 맞출 때 사용.
- **Ctrl+Backspace는 표 행을 삭제**한다. 사용자가 동시에 편집(사진 삽입 등)하면 화면이 밀려 엉뚱한 행(주소 줄)을 지운 적이 있다 → 지우기 전에 커서 위치를 확대해 확인하고, 실수는 Ctrl+Z.
- 쪽 맞추기: 표 크기는 두고 **섹션 제목 위 빈 줄을 하나씩 지워** 서약 문구를 1쪽에 올렸다(3쪽→2쪽). 학교명이 칸에서 두 줄이 되면 쪽이 다시 늘어 "대덕SW마이스터고"로 축약.
- **참고용 문서를 다른 탭으로 열면 양식 탭이 서버 연결이 끊김**("연결이 끊긴 상태에서 편집한 내용은 저장되지 않습니다"). 탭을 닫고 홈 카드로 다시 열었더니 이전 수정은 저장돼 있었다. 끊긴 상태에서는 입력하지 않는다.
- 붙여넣기가 멈추면 Chrome **클립보드 읽기 권한 창**일 수 있다 — Claude가 누르지 않고 사용자가 허용. 표 복붙은 엉뚱한 덩어리가 붙어 피하는 게 낫다.
- "임시 저장"과 **저장하기**는 별개 → 저장 후 "저장되었습니다" 확인. 표 테두리 잔상은 [[웹한글-표-글자처럼-취급-빈-첫쪽]].

## 디스코드 읽기 전용 수집
- 사용자가 직접 로그인한 Chrome 세션을 쓰고, **메시지 전송·입력은 검색창에만** 한다.
- 검색창 포커스를 `document.activeElement`로 **확인한 뒤에만 Enter**를 누른다 (배너가 사라지면 레이아웃이 밀려 클릭 위치가 어긋났다).
- 사용자명만으로 검색되지 않으면 **"보낸 이" 필터의 자동완성 목록에서 계정 선택**.
- 결과를 오래된 순으로 바꾸면 초기 대화도 읽을 수 있다. 페이지 넘김이 빠르면 검색 속도 제한에 걸려 **약 4.5초 간격**으로 천천히 넘겼다.
- `javascript_tool` 출력이 "쿠키/쿼리스트링 데이터"로 차단되면 출력에서 URL·특수문자를 제거해 반환한다.
- DM은 열지 않고, 작업 후 Chrome에 로그인이 남으므로 사용자에게 로그아웃을 안내한다.
