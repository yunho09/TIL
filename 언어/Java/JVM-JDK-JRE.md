# JDK(Java Development Kit)

- Java 프로그램을 개발하기 위해 필요한 도구 모음이다. 
- JDK는 Java 컴파일러, 디버깅 도구, 자바 가상 머신 (JVM) 등을 포함하고있다.
# JRE(java Runtime Evironment)

- Java 런타임 환경(JRE)은 Java 프로그램이 올바르게 실행되기 위해 필요한 소프트웨어이다.
- 자바 코드를 실행하기 위한 도구들로 구성된 패키지이다.
